# Capstone Fantasy class diagrams

- `overview.svg` shows the major relationships across the application, model, views, and persistence.
- `model.svg`, `view.svg`, and `io.svg` list the named types in each package, including nested types, with selected fields and public methods.
- The matching `.dot` files are editable Graphviz sources. Solid lines with hollow triangles represent inheritance; dashed lines with hollow triangles represent interface implementation. Dotted arrows indicate field references or nesting; they do not assert composition or ownership.

The diagrams abbreviate members with an ellipsis and do not include Java library classes. Consult the source for complete signatures and cross-package dependencies. The assignment also calls for a separate hand-drawn diagram; these digital diagrams do not fulfill that requirement.
